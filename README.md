# @webship.co/workspace-headless-ui

Headless UI for the [Webship Workspace](https://github.com/webship/workspace) dashboard: a builder that makes an app with
Headless UI, Tailwind Labs' unstyled, accessible components (with the Headless UI step pack's demo, or a starter alone), or
takes one from its repository, builds it and serves its production build from a container of its own; the
[Headless UI step pack](https://github.com/webship/headless-ui-steps) wired into the testing setup of that app; and its AI
items for building and testing Headless UI apps.

The builder, its functions, its testing hook and its AI items come with the first release, `1.0.0`.
